# AI-Based Cardiovascular Disease Risk Prediction System

## Project Overview

This project is a Machine Learning based web application that predicts the risk of cardiovascular disease using patient health data. The system allows doctors to input patient information, analyze risk levels, store patient records, and generate medical reports.

The application is built using Python, Streamlit, and a trained Machine Learning model.

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- Pandas
- NumPy
- SQLite
- Plotly
- ReportLab

## Dataset

The model was trained using the Cardiovascular Disease dataset from Kaggle. The dataset includes medical parameters such as:

- Age
- Gender
- Height
- Weight
- Blood Pressure
- Cholesterol
- Glucose
- Smoking Habit
- Alcohol Consumption
- Physical Activity

These parameters are used by the machine learning model to predict the risk of heart disease.

## Features

- Machine Learning based cardiovascular risk prediction
- Patient health data entry form
- BMI calculation and classification
- Risk probability analysis
- Interactive risk gauge visualization
- Patient data storage using SQLite database
- Patient record management (Edit/Delete)
- Data visualization dashboard
- PDF patient health report generation
- Role-based login system (Admin / Doctor)
